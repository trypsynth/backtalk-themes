# Backtalk sound themes

Sound themes for [Backtalk](https://github.com/trypsynth/backtalk).

## Install

Installing from this repository needs Backtalk build 392 or newer.

Add this repository as a sound theme source in Backtalk:

1. In Backtalk settings, go to **Sound themes**, and under **Install a theme**, choose **From a source**.
2. Choose **Add source**, and enter `github.com/trypsynth/backtalk-themes`.
3. Open the source, and choose a theme to install.

To install a single theme instead, share its link or its file to Backtalk.

## Themes

| Theme | What it sounds like |
| --- | --- |
| [TalkBack 5](TalkBack5.zip) | The sounds of TalkBack 5.0: MIDI notes for most events. |

## Adding a theme

Each theme is one ZIP file at the top of this repository, with its `theme.json` and its sounds inside. See [the sound theme guide](https://github.com/trypsynth/backtalk/blob/master/themes.md) for how to make one. Pull requests are welcome: add the ZIP file, and a row for it in the table above.
